STARLOG AUTHENTICATION SETUP

The Starlog application is configured to use email confirmation links rather than six-digit one-time codes.

1. In the Supabase dashboard, open Authentication > Email Templates.
2. For Confirm signup, use {{ .Token }} in the message. Do not use {{ .ConfirmationURL }}.
3. For Reset Password, use {{ .Token }} in the message. Do not use {{ .ConfirmationURL }}.
4. For Magic Link, if this template is used for email confirmation, use the confirmation link provided by Supabase; do not build the template around a one-time code.
5. Keep the message branded only as Starlog. Do not include provider names, provider URLs, dashboard URLs, or hosted-project URLs.
6. For phone authentication, enable Phone provider and configure your SMS provider. The SMS template should contain {{ .Code }} and Starlog-only wording.

Suggested email subject: Your Starlog verification code
Suggested email body:

Starlog
Your verification code is {{ .Token }}

This code expires soon. If you did not request this code, you can ignore this message.

Suggested password-reset subject: Your Starlog password reset code
Suggested password-reset body:

Starlog
Your password reset code is {{ .Token }}

Enter this six-digit code in Starlog to choose a new password. If you did not request a password reset, you can ignore this message.

IMPORTANT
Email/SMS templates are stored in the authentication service settings, not in PostgreSQL tables. Running the Starlog SQL schema cannot change those templates. The downloaded frontend already verifies six-digit codes; the dashboard templates above are required so the message delivered to users contains a code instead of a URL.

For the sender address, configure a sender/SMTP service you control under the authentication SMTP settings. Use a Starlog sender name and your own sender address.

Password recovery behavior:
- Email account: password-reset email link -> set new password.
- Phone authentication is not used by Starlog..

Login behavior:
- Password is checked first.
- A six-digit email/SMS code is then sent.
- The code must be verified before the login flow completes.
